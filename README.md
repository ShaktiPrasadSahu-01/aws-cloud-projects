# ☁️ AWS Cloud Architecture & Infrastructure Portfolio

Welcome to my **AWS Cloud Project** repo.

This repository is a collection of the **AWS projects and practical labs** I have completed while building my foundation in AWS Cloud (Networking, Infrastructure, Security, and Solutions Architecture).

The projects are primarily aligned with the **AWS Solutions Architect – Associate (SAA)** architectural domains and cover real-world concepts such as secure architecture, resilient infrastructure, high performance, cost optimization, networking, identity and access management, compute, storage, governance, and Infrastructure as Code.
